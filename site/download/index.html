What's in a release

Each release on GitHub holds these files, where V is its version. A version like 0.1.0-rc.1 is a release candidate, marked Preview: it may have rough edges. A plain 0.1.0 is stable.

FileWhat it is
Emberhut-V-macos-universal.dmgThe Mac app, with the hut inside. Apple silicon and Intel, macOS 13 or later. Signed and notarized by Apple.
Emberhut-V-windows-x64.msiThe Windows app, with the hut inside. Windows 10 and 11, 64-bit. Installs for you alone, with no admin prompt. Not code-signed yet.
emberhut-server-V-linux-x64.tar.gz, …-linux-arm64.tar.gz, …-macos-universal.tar.gz, …-windows-x64.zipThe hut on its own, as a server, for a computer that stays on.
SHA256SUMS, SHA256SUMS.minisigThe checksum of every file, and their signature.

Windows, while the installer isn't signed

The Windows installer doesn't have a code-signing certificate yet, so Windows SmartScreen may stop it with "Windows protected your PC". To install it anyway:

  1. Check the download against SHA256SUMS first (below).
  2. Open the .msi. If SmartScreen warns, choose More info, then Run anyway.
  3. It installs to %LOCALAPPDATA%\Programs\Emberhut and adds Emberhut to the Start menu. Remove it from Settings → Apps.

The phone

The iPhone and Android apps are in testing, through TestFlight and Google Play's testing track, and not in the stores yet. They pair with the hut on your Mac or PC. Join the waitlist and we'll write once when they're out.

Check a download

Compare a file's SHA-256 with its line in SHA256SUMS:

shasum -a 256 Emberhut-V-macos-universal.dmg          # macOS
certutil -hashfile Emberhut-V-windows-x64.msi SHA256  # Windows
sha256sum -c SHA256SUMS --ignore-missing              # Linux

Then check that SHA256SUMS itself is ours, with minisign and the release key:

minisign -Vm SHA256SUMS -P RWRER1atPjEA/9GrQdW+h0cy57Fiy526c7fbp1tkAabdvdSNURP3nnyD

The install guide has every step, for each system.
